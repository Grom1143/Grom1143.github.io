# grom1143.github.io

Корень сайта на GitHub Pages.

- `.well-known/assetlinks.json` – подтверждение, что Android-приложение **МикроТест Петри** (`io.github.grom1143.microtest`)
  принадлежит этому сайту. Без него приложение показывало бы сверху строку с адресом.
- `index.html` – переход на сайт https://grom1143.github.io/zona/
- `.nojekyll` – чтобы GitHub Pages публиковал папку `.well-known` (папки с точкой в начале он иначе пропускает).
